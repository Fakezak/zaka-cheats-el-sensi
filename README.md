# Zaka Sensi — Single-File Website

This package contains the complete Zaka Sensi website in one HTML document. The file includes the page markup, compiled CSS, compiled JavaScript, responsive behavior, generator interactions, and UI components inline.

## Use locally

Open `index.html` directly in a modern browser, or upload it to any static host. No `node_modules`, build step, framework installation, or separate asset bundle is required for the page itself.

## GitHub

Upload `index.html` and enable GitHub Pages for the repository. The preview image and video remain external media URLs, so the browser needs an internet connection to load them.

## Audio autoplay note

The video is configured for autoplay, normal volume, inline playback, and looping. Browsers may still block sound-on autoplay until the visitor interacts with the page.
